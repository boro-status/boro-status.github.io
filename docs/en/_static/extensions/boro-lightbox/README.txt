Lightbox2 vendored assets
========================

Upstream project: https://github.com/lokesh/lightbox2
Version: 2.12.0
License: MIT (see LICENSE.txt)

This project vendors standalone Lightbox2 distribution files and does not use
the bundled lightbox-plus-jquery file or its source map. The page uses Sphinx's
own jQuery dependency. The local options.js sets the
sanitizeTitle option to true to render thumbnail captions as text.

The CSS-relative image paths are kept in the images/ directory.
